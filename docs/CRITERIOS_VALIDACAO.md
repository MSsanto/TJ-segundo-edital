# Critérios para considerar cada módulo validado

1. **Escopo:** cargo Oficial de Justiça, conteúdo contemplado no Anexo VIII.
2. **Rastreabilidade:** todos os enunciados jurídicos precisam apontar artigo, diploma e versão de referência.
3. **Integridade de fonte:** comparar texto do livro com redação vigente, incisos, parágrafos, ressalvas e remissões.
4. **Explicação:** introdução acessível, exemplo concreto, um fluxograma de decisão.
5. **Exercícios:** questões com cinco alternativas críveis, uma correta sem ambiguidade, comentários sobre distratores.
6. **Discursiva:** modelo de aplicação com rubrica de domínio técnico, fundamentação e clareza.
7. **Acessibilidade:** PDF pesquisável, cabeçalhos navegáveis, contraste, largura legível e texto alternativo para diagramas essenciais.
8. **QA:** validação automática + inspeção visual + revisão jurídica de amostra, registrando responsável/data.

Os módulos 02–20 têm estrutura e conteúdo ampliado mas **não** obtiveram todas as oito validações. Não usar status “homologado” até satisfazê-las.
